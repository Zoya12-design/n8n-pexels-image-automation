# n8n Pexels Image Automation

## Overview

This project is an automated workflow built in n8n. It allows users to enter a keyword and automatically fetches images from the Pexels API and uploads them to Google Drive.

## Features

* Chat-based keyword input
* Fetch images using Pexels API
* Download images automatically
* Upload images to Google Drive

## Workflow Steps

1. User enters a keyword
2. HTTP Request calls Pexels API
3. Extract image URLs
4. Download images
5. Upload to Google Drive

## Requirements

* n8n
* Pexels API Key
* Google Drive account

## How to Use

1. Import the workflow.json file into n8n
2. Add your Pexels API key
3. Configure Google Drive credentials
4. Run the workflow
